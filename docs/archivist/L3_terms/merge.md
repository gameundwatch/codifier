# merge — 統合

同じことを言う二枚の決断を一枚にまとめること。

- Aliases: 統合, MERGE
- Details:
  - 先発を残し、後発を消す。
  - 後発を参照していた決断は、参照先を先発へ繋ぎ直す。
  - 先発の被参照数が増えるため、統合がエスカレーションを引き起こすことがある。
