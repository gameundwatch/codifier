# kind — 種別

決断が覆しにくい決定か、揃えるための取り決めかを分ける属性。

- Aliases: 種別, KIND
- Details:
  - 二つしかない。覆しにくい決定と、揃えるための取り決め。
  - 別案でも系が動くかどうかで分かれる。重要度の分類ではない。
  - 定義は種別ではない。語の定めは取り決めとして判定でき、terms へ還元される。
