# definition — 定義

名前と対象を結びつける行為。捨てた案を持たない条項。

- Aliases: 定義, DEFINITION
- Details:
  - 理由を持たない。決めたことそのものであり、決めた経緯を要しない。
  - コードから直に拾う。徴候を要しない。書いてあれば、それが定義であるため。
  - 定義そのものは篩にならない。関数の中の束縛も定義であるため。
  - decision と並ぶ、条項の一方。
