# definition — 定義

名前と対象を結びつける行為であり、それ自体が一つの決断。

- Aliases: 定義, DEFINITION
- Details:
  - 決まっていることの証拠ではなく、決まったことそのもの。理由を持たない。
  - sign と並ぶ、収集の第二の入口にあたる。履歴からは sign で、コードからは definition で拾う。
  - 捨てた案を持たずに成立する。この点で、履歴を要する決断と異なる。
  - 定義そのものは篩にならない。関数の中の束縛も定義であるため。
