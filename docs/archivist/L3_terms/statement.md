# statement — 確定事項

条項が何を決めたかを述べる欄。

- Aliases: 確定事項, STATEMENT
- Details:
  - 粒度によらず、三段すべてが持つ。
  - 二枚の条項がここで同じことを言わない。互いに素であることはこの欄で判定される。
