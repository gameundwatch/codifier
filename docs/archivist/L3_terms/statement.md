# statement — 決断事項

決断が何を決めたかを述べる欄。

- Aliases: 決断事項, STATEMENT
- Details:
  - 粒度によらず、三段すべてが持つ。
  - 二枚の決断がここで同じことを言わない。互いに素であることはこの欄で判定される。
