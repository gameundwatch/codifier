# principle — 原則

多数の条項が拠って立つ、最大の粒度の条項。ADR に相当する。

- Aliases: 原則, PRINCIPLE
- Details:
  - 確定事項と根拠に加えて、理由を複数行持つ。
  - 拠って立たれている数が多いほど、覆すときに影響を測る必要があるため。
  - convention から上がった状態。上がる閾値は利用者が決める。
