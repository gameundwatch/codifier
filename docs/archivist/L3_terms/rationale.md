# rationale — 理由

その条項に至った理由を述べる欄。

- Aliases: 理由, RATIONALE
- Details:
  - choice は持たない。convention は単一行、principle は複数行を持つ。
  - 拠って立たれている数が多いほど、覆すときに影響を測る必要があるため増える。
  - 粒度が下がらないため、一度書いた理由が機械的に消えることはない。
