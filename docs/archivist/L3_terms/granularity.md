# granularity — 粒度

決断が他の決断からどれだけ拠って立たれているかを表す段階。

- Aliases: 粒度, GRANULARITY
- Details:
  - 被参照数で決まる。人が選ばない。
  - choice / convention / principle の三段。
  - 上がるほど記載する内容が増える。
  - 上がることはあっても下がらない。
