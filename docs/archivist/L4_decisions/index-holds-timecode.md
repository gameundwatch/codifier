# 索引は条項発効時の timecode を持つ

索引の列を path・statement・granularity・grounds・timecode の五つとする。
timecode は条項が発効した時刻、すなわち徴候が成立したコミットの時刻を指す。
条項ファイルを書き出した時刻ではない。

重複を統合するとき、どちらが先発かをこの列で判定する。CSV の行順は作り直しのたびに
変わりうるため、順序を行の位置に持たせない。

時刻は履歴に対して強い。ファイルが動いても、索引を再生成しても変わらない。
書き出した時刻を採ると、走査範囲の切り方で前後が入れ替わる。
通し番号を併せて持つかは、まだ決めていない。
