# 篩は、定義スコープの外から名指しされていること

定義そのものは篩にならない。関数の中の束縛も定義である。

拾うのは、定義されたスコープの外から名指しされている識別子だけとする。外から名指し
されているなら、その識別子は公開されている。逆は成り立たないが、誰も名指ししていない
公開識別子はまだ何も壊しておらず、決まっていない。

可視性の規則を判定に使わない。export、pub、アクセス修飾子は言語ごとに増え、判定手段の
側から仕様が閉じなくなる。名指しは本体とテストの双方を数え、ドキュメント内の言及は
数えない。ドキュメントは壊れても気づかれず、変えられないことの証拠にならない。

この入口で拾った条項の timecode は、初めて外から名指しされたコミットの時刻になる。
篩が成立した時刻がそれにあたる。
