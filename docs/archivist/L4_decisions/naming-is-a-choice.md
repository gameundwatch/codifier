# 公開された識別子の命名は、個別に choice として拾う

拾うのは個別の名前であり、命名規則ではない。同じ形が反復すれば、被参照数が閾値を超えた
時点で escalation が convention へ上げる。最初から規則として拾うと、名前の一枚と規則の
一枚が同じことを言う。

確定事項には、名前、それが指す対象、どこから名指しできるか、そして同じ概念に別の綴りが
併存していればその併存を書く。別綴りの併存は、命名がまだ決まっていない状態を炙り出す。
併存していること自体は確定した事実なので拾い、解消は利用者に残す。

過去に改名があれば、そのコミットを `z2. 実装` に並べる。改名は捨てた案そのものだが、
理由欄を得るために粒度を上げることはしない。粒度は被参照数だけが決める。公開の深さも
同じ理由で属性に持たない。
