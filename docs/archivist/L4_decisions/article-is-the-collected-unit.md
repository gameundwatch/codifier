# 集める単位は条項とし、decision と definition に分ける

codifier が集める単位を article(条項) と呼ぶ。条項は decision(決断) と definition(定義)
の二種からなり、分かれ目は捨てた案を持つか否かの一点だけとする。互いに素であること、
粒度、参照、近傍図、欄の構成は条項が定め、二種の別によらない。

definition は decision の一種ではない。定義を決断の一種と置くと、決断が「捨てた案との
対で成立するもの」と「そうでないもの」の両方を指すことになり、語が二つの意味を持つ。
名前と対象を結びつける行為に捨てた案は要らないため、この二つは並ぶ関係にある。

上位語に article を選んだのは、決める行為の含みを持たないため。決断も定義も等しく載る
器に、行為の色は要らない。

入口が履歴とコードの二つに分かれるのは、この線の結果であって、線そのものではない。
徴候は decision を履歴から判定する篩であり、definition には掛からない。
