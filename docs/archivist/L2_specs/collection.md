# collection — 決断を集める要件

## Requirements

<a id="R1"></a>

### R1 入口を履歴と定義の二つ持つ

- 履歴の入口では、差戻し、書き換えの前後、収束した変更列を捨てた案として読む
- 定義の入口では、コードが指している決断の写像を書く。捨てた案を持たない
- 履歴を読まずにコードだけを入力にしない

<a id="R2"></a>

### R2 徴候を持つものだけを集める

- 徴候は反復・収束・差戻し・不動の四つ
- いずれか一つを持てば集める

<a id="R3"></a>

### R3 徴候を持たないものは集めない

- 一度きりの変更、揺れ続けている箇所は対象外
- 対象外にした理由を報告に残す

<a id="R4"></a>

### R4 一件ずつ人に問い合わせない

- 収集の途中で判断を人に委ねない
- 走査の範囲は開始前に人が決める

<a id="R5"></a>

### R5 候補に発効時刻を付ける

- 徴候が成立したコミットの時刻を取る
- 収集を実行した時刻や、決断ファイルを書いた時刻を使わない
- 徴候が複数のコミットにまたがるときは、成立した最後のコミットを採る
- 定義の入口では、初めて外から名指しされたコミットの時刻を取る

<a id="R6"></a>

### R6 定義の入口は、外から名指しされた識別子だけを集める

- 定義されたスコープの外から名指しされているものだけを集める
- 名指しは本体とテストの双方を数える
- ドキュメント内の言及は名指しに数えない
- 可視性の規則では判定しない。export やアクセス修飾子を条件にしない
- 誰も名指ししていない公開識別子は集めない

<a id="R7"></a>

### R7 命名は個別の名前として集める

- 命名規則としてまとめない
- 決断事項に、名前・対象・どこから名指しできるかを書く
- 同じ概念に別綴りが併存していれば、その併存を書く。解消はしない
- 公開の深さを属性として持たない

<a id="R8"></a>

### R8 公開識別子の改名は覆りとして扱う

- 既にある命名の決断の名前を書き換えない
- 過去の改名コミットは、根拠の実装欄に置く
- 改名を理由に粒度を上げない

<a id="R9"></a>

### R9 件数は入口ごとに分けて示す

- 履歴から何件、定義から何件かを分けて示す
- 合算した一つの数だけを示さない

<a id="V1"></a>

### V1 履歴が入力に入る

- Means: checklist
- 同じ最終状態で履歴の異なる二つのリポジトリを与え、集まる決断が異なることを見る

<a id="V2"></a>

### V2 徴候による採用

- Means: checklist
- 四つの徴候それぞれを一つだけ持つ変更を与え、いずれも決断として集まることを見る

<a id="V3"></a>

### V3 徴候なしの除外

- Means: checklist
- 一度きりの変更だけを含むリポジトリを与え、決断が生成されないことを見る

<a id="V4"></a>

### V4 問い合わせの不在

- Means: checklist
- 範囲を与えた後、完了までに人への問いが発生しないことを見る

<a id="V5"></a>

### V5 発効時刻の出処

- Means: checklist
- 同じリポジトリを日を変えて二度収集し、候補に付く時刻が一致することを見る

<a id="V6"></a>

### V6 名指しのない公開識別子の除外

- Means: checklist
- 公開されているがどこからも名指しされていない識別子だけを含む範囲を与え、決断が生成されないことを見る

<a id="V7"></a>

### V7 テストからの名指し

- Means: checklist
- 本体からは名指しされず、テストからのみ名指しされる識別子を与え、決断として集まることを見る

<a id="V8"></a>

### V8 ドキュメントの言及の除外

- Means: checklist
- コードからは名指しされず、ドキュメントにのみ名前が現れる識別子を与え、集まらないことを見る

<a id="V9"></a>

### V9 別綴り併存の記載

- Means: checklist
- 同じ概念に二つの綴りが公開され双方が名指しされている範囲を与え、決断事項に併存が書かれることを見る

<a id="V10"></a>

### V10 規則にまとめないこと

- Means: checklist
- 同じ綴り方の識別子を複数与え、規則を述べる決断が一枚も生成されず、名前ごとの決断が並ぶことを見る

<a id="V11"></a>

### V11 改名後の覆り

- Means: checklist
- 命名の決断がある状態でその識別子を改名し、決断事項の名前が書き換わらず、打ち消し線が引かれることを見る

<a id="V12"></a>

### V12 件数の分割表示

- Means: checklist
- 両方の入口に材料のある範囲を与え、履歴からの件数と定義からの件数が別々に示されることを見る
